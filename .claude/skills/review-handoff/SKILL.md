# 修正対象の確認・引き継ぎテンプレート

統合最終レポートを出力した後、このスキルのテンプレートを使ってユーザーに確認する。
確認を受けてから dev-team-lead への引き継ぎを行う。確認なしに修正を開始しない。

## Step 1: ユーザーへの確認

以下のフォーマットで確認する（番号・タイトル・説明は実際のレポート内容に合わせて埋める）:

```
## 修正対象の確認

🔴 今回のPRに含める（今すぐ修正が必要）:
  - B-1: [タイトル] — [1行説明]
  - S-1: [タイトル] — [1行説明]

🟡 別Issueで対応可（次スプリント以降）:
  - U-1: [タイトル]
  - S-2: [タイトル]

Q: 🔴 B/S項目をこのまま修正しますか？
Q: 🟡 U/S項目のうち、今回対応するものがあれば番号を教えてください。
```

## Step 2: dev-team-lead への引き継ぎ

ユーザーの回答を受けて、対応する指摘番号のリストを dev-team-lead に渡す。
上記以外の指摘は今回対応しないよう明示することで、スコープの膨張を防ぐ。

```
review-team-lead からの引き継ぎです。
以下のレビュー指摘を修正してください：
- B-1: [内容・場所・修正方針]
- S-1: [内容・場所・修正方針]

上記以外の指摘は今回対応しないでください。
```
