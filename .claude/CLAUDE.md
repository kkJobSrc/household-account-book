# 家計簿
## outline
家庭内のLAN で完結する会計簿アプリの開発
収支の登録とレポート集計をする

## stack
- 言語: Python 3.12
- FW:   React, TypeScript, Vite, FastAPI
- DB:   SQLite

## Rules
### 禁止事項
- ライブラリのインストールを勝手にしないこと
- ログファイルの出力はworkspace 外に出す設計をしないこと

### 出力形式
- ソースコード(機能部品)には 英語でコメントする
- ドキュメント(非機能部品)には日本語でコメントする

### agnents,skills
- 具体的にステップの決まっている作業は、skills に作成し参照するようする
- パスを記載するときは、worksapce 内の相対パスで記載

### 相談（全エージェント共通）
以下の場合は必ずユーザーに確認し、推定で進めない：
- 要件に複数の解釈が成立する
- DBスキーマ変更・既存データへの影響がある
- APIコントラクトに後方互換性の問題が生じうる
- issueに明示されていない動作（暗黙の仕様）に踏み込む
- セキュリティ・認証に関わる設計を新たに行う
- 既存コードの拡張性・保守性を著しく下げる実装方針を取る場合

### 評価・振り返り（全エージェント共通）
作業中に再試行・失敗が発生した場合は以下の手順を踏む：
- **失敗時の検索**: 再試行前に `.claude/reference/` を検索し、過去の類似事例を確認する
  ```bash
  find .claude/reference/ -name "*.md" 2>/dev/null | xargs grep -l "<キーワード>" 2>/dev/null
  ```
- **作業完了後の記録**: 再試行が1回以上あった場合、`.claude/reference/YYYY_MM_DD_<kebab-case-title>.md` を作成する
- **改善案の提案**: 同種の失敗が繰り返された場合、エージェント定義やスキルの改善案をユーザーに提案する
